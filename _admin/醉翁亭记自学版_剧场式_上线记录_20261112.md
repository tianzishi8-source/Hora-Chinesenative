# 《醉翁亭记》自学版改版（剧场式）上线记录 · 2026-11-12

## 为什么改
老师反馈：九年级的自学界面（zx/ 引擎，一块一块往下点）比较枯燥。要求：**解读深度对照《岳阳楼记》，形式对照八年级《蜘蛛》《皇帝的新装》的自学课**。先做《醉翁亭记》一课当样板，老师试过、提了意见，再照样改《洞庭三诗》《游岳阳楼记》《最苦与最乐·谈生命》。

## 做了什么
- 文件夹 `zuiweng/` 整个换成剧场式引擎（从 `xinzhuang/engine.js` 复制，另加 `trans` 逐句翻译步骤：原句分色 → 自己先说 → 看译文，原文和译文同色对应、标出“留／换／补／调” → 自评说对了／差一点／没说出来；领读会把原句和译文读出来）。
- 课文 id 改为 `g9-zuiweng-zx`（lessons.js 同步改），旧 zx 自学版的进度不再沿用。
- 领读：**琅琊山的山雀**（虚构，印章“雀”，以后可换立绘）。它“知山林之乐，而不知人之乐”，带着“人到山里乐什么”的疑问上山，第4天自己想明白。伴学清弦／长歌、徽音老师、小满、林一、阿禾照旧；欧阳修在第3、4天露面（虚构的话都标“课外的话”）。
- 4 天：
  1. **山行六七里**（第1段）：背景（庆历五年被贬、同年范仲淹写《岳阳楼记》）→ 读全文 → 正音 → 场景“跟着镜头上山”（山→西南诸峰→听水声→酿泉→亭）→ 5 句逐句翻译 → 设问、“年又最高”（《题滁州醉翁亭》四十未为老）→ 小满误用“醉翁之意不在酒”的辨析 → 仿写“镜头推近”。
  2. **朝而往，暮而归**（第2段）：复习 → 场景“一亭四季”（六张原文卡片，亭子换朝暮四季）→ 3 句翻译 → “秀”一词多义 → 有“而”和没“而”对听 → 景变乐不变 → 找判断句 → 仿写“一句一季”。
  3. **滁人游，太守宴**（第3段）：复习 → 场景“山里的一天”（点四群人：游、宴、欢、醉）→ 4 句翻译 → 非丝非竹 → 为什么先写滁人、热闹中的太守 → 独立作答“太守为什么醉”（点原文找依据，可匿名分享）＋三位虚拟同学（醉于山水／借酒消愁／醉于民乐）→ 仿写“分组写场面”。
  4. **太守之乐其乐**（第4段、全文）：4 句翻译 → 场景“三层乐”（禽鸟→游人→太守）→ 同其乐、篇末点题与首尾呼应、线索“乐” → 场景“找出二十一个也”＋有“也”没“也”对听 → 与《岳阳楼记》比较（先忧后乐）＋独立作答“替欧阳修回应范仲淹” → 场景“背一背”（每段三轮：全文 → 藏一半 → 只留每句首字）→ 山雀的答案、对欧阳修说一句。
- 练习：每天一组，16 道基础检测＋12 道错题相似新题。笔记本：三篇仿写、两次独立作答、对欧阳修说的话；记录页有全文结构和自己写过的翻译。
- 画面：先用 `ke/scene.js` 画的 SVG（mount／path／stream／pavilion 各色调／feast）；`zuiweng-ke/img/` 里有真图（scene-名字[-色调].webp）时自动换真图，GPT 出的图放进去即生效。
- 录音：416 条（Edge TTS），`zuiweng/tools/lines.js` 生成清单（多音字按词组替换：乐→勒、射者中→射者众、朝→招、琅琊→郎牙等；带拼音的回应整句改读）、`tools/record.py` 录。

## 审核
独立审校后改了：全文“四百来个字”、第2段“而”有八个；翻译方法标签（得之心／寓之酒、山行标“补”，休于树标“调”，其西南诸峰标“换”）；“尤”的干扰项换成“过失”；“非丝非竹”题干改为“乐趣不在音乐”；“安居乐业”；“外貌和神态描写”；《朱子语类》记载的初稿轶事、滕子京“凭栏大恸”标明出处。“渐闻水声潺潺，而泻出……”的逗号按课堂版所用课本文本保留（部编版无逗号，请老师对照学生课本）。

## 11-12 下午 · 按老师第一次试用的意见改版（9 条）
1. **跟着镜头上山**：不再让学生看图猜方向（图上看不出西南）。每一步改成按原文填空（环滁皆＿也 / 其＿＿诸峰 / 渐闻＿＿潺潺 / 泻出于＿＿之间 / 有＿翼然），填对了镜头才往前推。
2. **逐句翻译必须先写**：没写够字数（按句长 4—8 字），“看译文”按不下去。
3. **“醉翁之意不在酒”讲清楚**：先问“意”（情趣），再整句翻译，再用一张卡对照原意（坦白自己的情趣在山水）和成语义（表面做一件事、另有目的，多含贬义），两道辨析题分别判断小满的用法和原文的用法。
4. **字词大大加量**：每句先过关键字再连句。新的“字词卡”（ask）：学生自己写意思 → 错了给提示 → 再错给第二条提示 → 还不对才给三个选项。第1段 12 个、第2段 9 个、第3段 10 个、第4段 7 个，外加整句翻译 17 句。
5. **答错只给提示**：所有选择题错项的回应改成“回到哪一句、看哪个字、想想注释”，不直接说答案。
6. **写法让学生自己说**：由远及近、总起、设问、抓特征、判断句、衬托（以动衬静）、层层衬托、与民同乐、线索“乐”，都改成先让学生自己写出来（ask），对了才讲。
7. **练习题库全部预先写好，不现场生成**：课上 66 道判分题＋基础检测 16 道，共 82 道，每道都配一道“相似新题”（同一知识点、换角度问）。课上或基础检测错过的题，在“旧题和新题”里先原题重做、再做新题（每组最多 10 道）。引擎改动：ask 题也进错题；基础检测错了也进“旧题和新题”。
8. **加入作者视角**：每天一个“问欧阳修”环节（每次三个问题，至少问一个），欧阳修用第一人称回答，内容依据课文和史料（《题滁州醉翁亭》、《宋史》“宽简而不扰”、庆历八年调扬州等），标明“根据课文和史料想象”。欧阳修头像用立绘裁出。
9. **先意思后脉络**：每天的顺序改成 复习 → 字词＋逐句翻译 → 场景 → 写法和结构 → 问欧阳修 → 仿写。
- 独立审校后又改了：几处提示还在泄露答案（“两个字：情……”之类）、accept 里会放过错答案的词（“对比”不算衬托、“上上下下”不算“上下”、“说”不算“谓”）、几个站不住的例词（苗而不秀、环顾、日行千里、百花齐发）、“乐其乐”与“先忧后乐”的比较措辞。
- 录音 769 条。四天＋第1组练习用自动脚本走通，没有报错。
