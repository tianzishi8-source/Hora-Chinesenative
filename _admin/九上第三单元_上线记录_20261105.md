## 程序

- `ke/`：课堂版通用引擎。它由《岳阳楼记》课堂版改造而来。每课只需要一个 `conf.js` 和 `data/`。
  - 新增的代码画场景：山、泉、亭、山路、宴饮、湖面、船舱、楼上凭栏、码头、酒楼、讲堂、江岸、一棵树，都带四季和天气色调。
  - 新增人物剪影 `figure(kind)`：没有立绘时先用它。
  - `yueyanglou-ke/` 仍用它自己原来的 app.js，没有改动。
- `zx/`：自学版通用引擎，数据驱动。
  - 页面结构：课时按钮 → 环节（计时）→ 块。
  - 块的种类：画面、人物对话（伴学清弦／长歌、徽音老师、作者）、原文（点句朗读、注音、注释、白话）、字音、单选、翻卡、连线、找句子、排序、想一想、练笔、背诵、对照表、知识卡、方法卡。
  - 练笔和课时进度会同步到表格，课文 id 分别是 `g9-zuiweng`、`g9-dongting`、`g9-youyyl`、`g9-kule`。课堂版的 id 后面加 `-ke`。
- 录音（Edge 声音，在仓库根目录运行）：
  - 课堂版：`node ke/tools/lines.js 文件夹 > /tmp/l.json && python3 ke/tools/record.py /tmp/l.json 文件夹`
  - 自学版：先运行 `node zx/tools/lines.js 文件夹`，再用同一个 `record.py`。
  - 声音表写在各课的 `conf.js` 或 `data/lesson.js` 的 `voices` 里。
  - 改了台词只需重新跑一遍，录过的句子会跳过。
- 检查：`node ke/tools/check.js 文件夹`。它检查跳转、原文卡里的词、字词卡原句、填空答案和总分。

## 审核

每课写完后，都由另一个审核员单独核对知识点。查出的问题已全部改正，主要有：
- 《题滁州醉翁亭》的引用和释义；
- 张丞相一说是张说；
- 孟浩然晚年入张九龄幕府；
- 滕子京当时知泾州，不是带兵救援定川；
- 袁中道当时已是举人，“还没中进士”；
- “据考证范仲淹未到岳阳”标明出自课本练习四；
- 若干个也能算对的干扰项。

课本 docx 里的错字已按定本改正，例如“滕宗琼”“庐陵钧命”。注释口径按北师大版课下注。与部编本不同的地方两说都给，例如“乐其乐”。
